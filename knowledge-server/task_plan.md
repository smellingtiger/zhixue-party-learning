## 问题描述
用户反馈知识库文件有很多加载失败的情况，需要诊断并修复。

## 可能的原因
1. 知识库服务加载文件时超时或内存不足
2. 文件编码或格式问题
3. 文件名包含特殊字符导致路径错误
4. 知识库索引文件未更新
5. 文件权限问题

## 计划执行步骤
1. 检查知识服务日志和API响应
2. 抽样检查失败加载的文件
3. 分析文件格式和编码问题
4. 修复加载逻辑或文件本身
5. 验证修复效果
